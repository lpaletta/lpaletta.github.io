This page contains illustrative animations of 2D signal-rule decoders introduced in Local decoding of the toric code under high noise, L. Paletta, 2026.

Each lattice site has a small local memory that stores the value of the local stabilizer measurement outcome (-1 values are called defects, shown in dark blue), along with 12 binary variables (1- and 2-forward signals, and 1- and 2-anti-signals, each subdivided by cardinal direction) and 6 integer variables (1- and 2-stacks, also subdivided by cardinal direction).

The rule aim to match defects by pair, by mediating an attractive interaction between them.

Signals are printed with the following priority order:

  • defect > 1-forward-signal > 2-forward-signal
  • 1-stack > 2-stack > 1-anti-signal > 2-anti-signal

Other printing rules include:

  • Several signals of the same type on the same site are indicated by a square
  • The maximum of the local stack is printed in white
